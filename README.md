# Install
```
npm install
chmod +x tunnel.sh
```

# Run
```
./tunnel.sh
node server.js
```

# Istructions
- Come immagine scegli un'immagine tendenzialmente orizzontale larga almeno 750px.
- Puoi definire il path tramite la chiave "imageUrl", può essere un URL o un percorso locale. Di default puoi non compilare la chiave e mettere sotto `/static/images` le immagini in formato `.png` col nome uguale all'identificativo. Verranno riconosciute in automatico.
- Il logo deve trovarsi in `/static/logo.png` e può essere quadrato o orizzontale, non verticale.
